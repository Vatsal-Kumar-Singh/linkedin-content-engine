# Revision pass

You are revising your own previous draft against independent feedback. The feedback came
from a separate reviewer that never saw your reasoning — treat it as an editor's mark-up,
not as a conversation.

**Rules for this pass:**

1. Fix every item listed. Where a replacement wording is supplied, use it or something
   demonstrably better — do not ignore it and do not paraphrase it into vagueness.
2. Change nothing that was not flagged. Gratuitous rewriting loses what already worked
   and makes the iteration history meaningless.
3. Do not argue with the feedback in the output. If a fix is wrong, implement the closest
   correct thing and note it in `sources_used`.
4. Return the **complete** JSON object, not a diff.
